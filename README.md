# JobsDAO-Rust

JobsDAO-Rust is a decentralized job marketplace built on Solana, using smart contracts written in Rust.  
The platform enables secure and trustless interactions between employers and freelancers, with governance and automation handled via Solana smart contracts.

---

## Features
- Decentralized job posting and application  
- Smart contract-based escrow for payments  
- DAO governance for job approvals and dispute resolution  
- Rust-powered Solana smart contracts  
- Example workflows for testing and development

---

## Prerequisites
- Rust (latest stable version)  
- Solana CLI v1.6.1 or later  
- Node.js and npm (for client-side testing)
